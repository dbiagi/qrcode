# Learnings

This folder records what was learned during development and debugging, so that later work (by humans or agents) doesn't have to rediscover it.

## How it works

- Each meaningful learning or finished debugging session gets its own file: `docs/learnings/<short-kebab-description>.md`.
- Each file should cover:
  - **Context**: what was being done and what symptom showed up.
  - **Root cause**: what was actually wrong.
  - **Fix / takeaway**: what changed, and the rule to follow from now on.
  - **References**: files, commits and links.
- Add a line to the list below for every new file.
- If a learning becomes a lasting rule, also add it to [../rules.md](../rules.md).
